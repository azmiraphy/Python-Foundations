## Topic 02 - Tuples
### Module 02 : Python Data Structure 

## Objective 

Learn how to store multiple values in an ordered and
immutable collection using Python tuples .

## Practice 
- Creating and accessing tuples
- Indexing and slicing 
- Checking elements with in
- Counting and finding elements
- Looping through tuples
- Tuples unpacking 
- Nested tuples
- Physics measurement data
- Returning multiple values from functions
- Understanding tuple immutability


## Learning Outcomes 

After completing this topic , I can:

- Create and access tuples
- Use indexing and slicing
- Use tuple methods
- Understand tuples with functions
- Work with nested tuples
- Unpack tuple values 
- Store fixed scientific data using tuples
